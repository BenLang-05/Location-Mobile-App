# GPS Location Recorder

An Android application developed in Java that allows users to record and manage GPS locations. 
The app allows the user to enter details including latitude and longitude, enabling users to save locations alongside custom names and notes for future reference.

## Features
GPS location tracking
Save locations with a custom name
View all saved locations in a list
Edit saved location details
Delete locations
Persistent local data storage

## Technologies Used
Java,
Android Studio,
SQLite,
Android SDK

## Project Overview
This application was developed for Android devices and functions as a simple location recording tool.
Users can capture their current GPS coordinates and store them for later viewing and management.
All recorded locations are stored locally on the device, allowing data to persist between sessions.

## Project Structure
The main application source code can be found in:
app/src/main/java/

Application resources such as layouts, images and strings can be found in:
app/src/main/res/

The Android manifest file is located at:
app/src/main/AndroidManifest.xml

## Setup
Open the project in Android Studio and allow Gradle to synchronise before running the application on an Android emulator or physical device.

## Notes
This repository is intended to showcase Android application development, including GPS integration, local data storage, and CRUD (Create, Read, Update, Delete) functionality.
The project was originally developed as part of a Mobile Application Development module.
